# EverGrims Paintings

Sushi bar and kitchen paintings for the [ImageFrame](https://github.com/LOOHP/ImageFrame) plugin, drawn for the
EverGrims Werks server. Every image is 128 px per block, one map per block, so it lands 1:1 on ImageFrame's maps.
Original pixel art, regenerated by `paintings.py` (Python standard library only).

## Retro 90s backlit set

Neon signs, desk toys and a lighted motion waterfall, made for **glow item frames**: a glow frame shows a map at full
brightness, so these read like lit signs and lightbox pictures in a dark room. The `.gif` pieces animate on Java;
Bedrock shows a GIF's first frame, and every first frame is drawn as a finished still (the neon signs fully lit, the
falls with its water lit). Every pixel is a Minecraft map colour (the 26.3 game's own table), so ImageFrame shows them
crisp, with no dithering. Sources in `retro-src/` (`python3 retro-src/neon/neon.py`, `desk/desk.py`, `falls/falls.py`
write beside themselves; copy the finished file up).

```
/imageframe create evergrims_falls https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/evergrims_falls_3x3.gif 3 3 combined
/imageframe create fish_tank https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/fish_tank_1x2.gif 2 1 combined
/imageframe create lava_lamp https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/lava_lamp_2x1.gif 1 2 combined
/imageframe create neon_closed https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/neon_closed_1x2.png 2 1 combined
/imageframe create neon_fishin_dock https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/neon_fishin_dock_2x3.gif 3 2 combined
/imageframe create neon_open https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/neon_open_1x2.png 2 1 combined
/imageframe create neon_sushi https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/neon_sushi_1x3.png 3 1 combined
/imageframe create plasma_globe https://raw.githubusercontent.com/Insanetricks91/evergrims-paintings/main/plasma_globe_2x2.gif 2 2 combined
```
